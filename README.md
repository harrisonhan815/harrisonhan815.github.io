## 语言切换

右上角中文 / EN 按钮会更新文案、网页标题、描述和页面语言，并保存本机偏好。

- `?lang=zh`：中文，例如 `https://harrisonhan815.github.io/?lang=zh`
- `?lang=en`：英文，例如 `https://harrisonhan815.github.io/?lang=en`

优先级为 URL 参数 → 已保存偏好 → 浏览器语言。禁用 JavaScript 时显示中文。
